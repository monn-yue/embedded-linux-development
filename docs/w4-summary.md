# W4：IMU 六轴采集验证

- 硬件：KICKPI K11C V1.2，Dawnoriginal ICM‑45688‑P + QMC6309。
- 接线：K11C 第 1 针 3.3 V → VCC，第 3 针 → GND，
  第 16 针 → SCL，第 18 针 → SDA。CS 留空。
- 总线：Debian 11 的 `/dev/i2c-3`，模块地址 `0x69`。
- 芯片身份：读取 `WHO_AM_I`（`0x72`），返回 `0xe7`。
- 六轴启用：向 `0x10` 写入 `0x0f`，读回 `0x0f`。
- 加速度验证：平放时 Z 轴为 1018，侧放时 Y 轴为 1007。
- 陀螺仪验证：静止时 Z 轴约为 −5，转动中读到 −3541，随后回落。
- 以上六轴读数为有符号原始整数。
