# IMU 模块与接线记录

## 1. 模块信息

- 模块：Dawnoriginal
- 传感器：ICM-45688-P + QMC6309
- 通信接口：I2C
- 引脚图来源：购买时的商家商品资料（原图不随仓库分发，原始商品链接暂未留存）。

## 2. 模块引脚

左侧 2×6 排针：

| 引脚 | 信号 |
|---|---|
| 1、2 | 3V3 |
| 3、4 | GND |
| 5、6 | SCL |
| 7、8 | SDA |
| 9、10 | CS |
| 11、12 | SDO |

右侧 2×5 排针：

| 引脚 | 商家资料标注 | 原图标记 |
|---|---|---|
| 1 | 未标注 | |
| 2 | NC | 叉号 |
| 3 | INT1 | |
| 4 | INT1 | 叉号 |
| 5 | SCX | |
| 6 | SCX | 叉号 |
| 7 | SDX | |
| 8 | SDX | 叉号 |
| 9 | CLK_CTL | |
| 10 | CLK_CTL | 叉号 |

说明：“叉号”仅为对原商家资料图中视觉标记的文字转录。原图未随仓库分发，且叉号的电气含义未得到独立确认，因此本记录不据此判断引脚状态或接线方式；实际接线以第 3 节的实测记录为准。


模块尺寸：15.00 × 15.05 mm，排针间距 2.54 mm。

## 3. K11C 接线

开发板：KICKPI K11C V1.2

| K11C 引脚 | 模块引脚 |
|---|---|
| Pin 1（3.3V） | VCC |
| Pin 3（GND） | GND |
| Pin 16（SCL） | SCL |
| Pin 18（SDA） | SDA |

CS 未连接，保持悬空。

以上为 W4 实际使用的接线方式。

## 4. I2C 信息

- Linux 设备节点：`/dev/i2c-3`
- I2C 地址：`0x69`
- WHO_AM_I 寄存器：`0x72`
- 实测返回值：`0xe7`

W4 已完成芯片身份验证及六轴数据读取。
